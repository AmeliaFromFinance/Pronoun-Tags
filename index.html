Browser extension for Twitch chat

Pronouns next to names, your way

Pronoun Tags shows the pronouns people set on pr.alejo.io right beside their name in Twitch chat.

Add to Chrome Add to Firefox

Free and open source. Works in Chrome, Edge, Brave, Opera, Vivaldi, Arc and Firefox.

Small, fast and private

Install it and tags show up. Open the toolbar button to change how they look.

All over Twitch

Chat, popout chat, mod view, the creator dashboard, VOD replays and About panels.

Six styles

Start from Classic, Name color, Outline, Subtle, Solid or Blush, then tweak.

Your wording

Capitals, brackets, separator, and one word or both. She/Her, (she/her) or SHE.

Live preview

See changes instantly in Twitch's dark or light theme. Open tabs update straight away.

Private

No servers, no analytics, no ads. Only usernames go to the pronouns API.

Works with FFZ

Tags appear in FrankerFaceZ chat too. 7TV chat is best effort.

Looks like part of Twitch

Tags follow your chat font size and sit neatly next to names. Use Twitch purple, each person's name color, or any color you like.

Gallery

Dark by default, with a soft pink accent.

Set your own pronouns

Tags come from pr.alejo.io. Sign in there with Twitch to set yours, and they'll show up for everyone using it. Pronoun Tags isn't affiliated with Twitch or pr.alejo.io. Privacy policy
